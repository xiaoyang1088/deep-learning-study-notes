# 实验22：CIFAR-10上ResNet20与ResNet56的从零训练及深度对比

## 摘要

本实验参考《Deep Residual Learning for Image Recognition》中针对CIFAR-10的模型结构与训练安排，使用PyTorch自行实现CIFAR版本的ResNet20和ResNet56，从随机初始化开始完成训练和最终测试。两种模型均采用Option A捷径、交叉熵损失、带动量和权重衰减的SGD优化器，并以64000次参数更新作为固定训练终点。

在本机单张NVIDIA GeForce RTX 5060 Laptop GPU上，ResNet20训练耗时36.71分钟，最终测试准确率为91.71%；ResNet56训练耗时62.63分钟，最终测试准确率为93.15%。本次运行中，56层模型比20层模型提高1.44个百分点，代价是更多参数和更长训练时间。

## 1. 实验目的

1. 自行实现适合32×32图片的CIFAR ResNet，理解其与ImageNet版本ResNet的结构区别。

2. 完成两种网络深度的充分训练，比较最终测试效果、参数数量和训练耗时。


## 2. 论文依据

本实验的主要依据是何恺明等人的ResNet论文第4.2节“CIFAR-10 and Analysis”。采用其CIFAR网络的三个残差阶段、6n+2层数安排及Option A捷径，并沿用批次128、动量0.9、权重衰减0.0001，以及在32000、48000次更新后降低学习率、64000次更新结束的训练安排。[1]

本实验与论文的关系是“参考主要结构与训练方法的学习实验”，而非全部条件的严格复现。

## 4. 实验方案

### 4.1 数据集与预处理

本实验使用CIFAR-10官方训练集和测试集，分别包含50000张和10000张32×32 RGB图片，类别数为10。两种模型使用相同的数据划分与预处理方法，不使用额外训练数据或预训练权重。

预处理首先根据全部训练图片计算逐像素、逐通道的平均图片，再从每张图片中减去对应均值。测试图片使用相同的训练均值，避免利用测试数据估计预处理统计量。具体处理如下：

| 数据 | 处理方式 |
|---|---|
| 训练集 | 转换为float32并减训练平均图片；四边补4个零，随机裁剪为32×32；以0.5概率水平翻转 |
| 测试集 | 转换为float32并减训练平均图片，不进行随机裁剪或翻转 |

实现中保留原始像素尺度，没有除以255；训练增强在减均值之后执行。测试采用原始32×32图片的单视图评估。

### 4.2 对比设计

实验以网络深度为主要比较因素，分别训练ResNet20和ResNet56。两组保持输入尺寸、阶段通道数、捷径方式、优化器、批次大小、学习率安排及更新次数一致，比较最终测试效果和实际训练成本。

本实验直接沿用论文给出的训练安排，使用全部50000张训练图片，不另设验证集。两种模型均在固定的64000次更新后测试，不根据中间测试结果选择模型。

| 比较项目 | ResNet20 | ResNet56 |
|---|---:|---:|
| 每阶段基本块数 | 3 | 9 |
| 基本块总数 | 9 | 27 |
| 阶段输出通道 | 16、32、64 | 16、32、64 |
| 可学习参数量 | 269722 | 853018 |
| 每批图片数 | 128 | 128 |
| 参数更新次数 | 64000 | 64000 |
| 随机种子 | 42 | 42 |



### 4.3 训练超参数

| 项目 | 设置 |
|---|---|
| 损失函数 | 平均交叉熵损失 |
| 优化器 | SGD |
| 动量 | 0.9 |
| 权重衰减 | 0.0001 |
| 权重衰减范围 | 全部可学习参数，包括BN参数和偏置 |
| 初始化 | 卷积使用He正态初始化；BN缩放参数为1、平移参数为0；分类层权重标准差0.01、偏置为0 |
| Dropout | 不使用 |
| 训练记录 | 每100次更新记录一次 |
| 测试模型 | 第64000次更新结束后的最终模型 |

学习率采用分段下降策略：

| 参数更新编号 | 学习率 |
|---|---:|
| 第1～32000次 | 0.1 |
| 第32001～48000次 | 0.01 |
| 第48001～64000次 | 0.001 |

训练加载器每次遍历重新打乱顺序，使用 `drop_last=True`，每遍提供390个完整批次，剩余80张在该遍不参与更新。训练总共处理8192000张次，在164次完整遍历后再处理40批达到终点。测试保留尾批，共79批，覆盖全部10000张图片。数据加载使用 `num_workers=0`。

## 5. 模型设计与实现

### 5.1 整体结构

模型采用适配CIFAR-10的ResNet结构：入口为3×3、步幅1卷积，不设置入口最大池化；主体包含三个残差阶段，通道数依次为16、32、64；最后通过全局平均池化和全连接层输出10个类别分数。

| 结构位置 | ResNet20配置 | ResNet56配置 | 输出尺寸，不含批次维 |
|---|---|---|---|
| 输入 | RGB图片 | RGB图片 | 3×32×32 |
| 入口 | 3×3卷积、BN、ReLU | 相同 | 16×32×32 |
| 第一阶段 | 3个基本块 | 9个基本块 | 16×32×32 |
| 第二阶段 | 3个基本块，首块下采样 | 9个基本块，首块下采样 | 32×16×16 |
| 第三阶段 | 3个基本块，首块下采样 | 9个基本块，首块下采样 | 64×8×8 |
| 全局平均池化 | 对每个通道的8×8空间位置求平均 | 相同 | 64 |
| 分类层 | 全连接层64→10 | 相同 | 10 |

每个基本块包含两层3×3主分支卷积。按入口卷积、主分支卷积和最终分类层计数，模型深度分别为：

```text
ResNet20：1＋3×3×2＋1＝20
ResNet56：1＋3×9×2＋1＝56
```

两种模型保持相同的阶段宽度，通过增加各阶段的残差块数量改变深度。

### 5.2 基本残差块与捷径

基本块主分支依次执行“3×3卷积—BN—ReLU—3×3卷积—BN”，随后与捷径分支相加，再经过ReLU输出。残差分支与捷径共同参与最终分类损失的优化。

输入输出形状一致时，使用恒等捷径直接保留输入。第二、第三阶段的首块在第一次卷积中采用步幅2，缩小空间尺寸并增加通道。对应捷径采用Option A：空间上间隔取样，通道维度补零，不引入可学习参数。



### 5.3 归一化、初始化与分类输出

各卷积后设置BN以调整中间特征分布。训练时BN使用当前批次统计量并更新运行均值、运行方差；测试时使用训练期间保存的运行统计量。BN采用PyTorch默认 `eps=1e-5`、`momentum=0.1`。

卷积采用 `kaiming_normal_` 初始化，设置 `fan_in` 和ReLU对应增益。全局平均池化将每个通道的空间特征概括为一个数值，再由分类层输出10个原始类别分数。训练直接使用交叉熵处理这些分数，不在模型末尾额外添加Softmax；预测取最大分数对应的类别。

## 6. 训练与评估方法

### 6.1 参数更新过程

模型从随机初始化开始训练。每次更新取128张增强后的训练图片，前向得到形状为 `[128,10]` 的分类分数，与真实标签计算平均交叉熵损失，并完成反向传播和SGD更新。核心过程为：

```python
optimizer.zero_grad()
outputs=model(images)
loss=criterion(outputs,labels)
loss.backward()
optimizer.step()
```

其中，反向传播计算各参数对损失的梯度，优化器根据梯度、学习率、动量和权重衰减修改参数。动量积累历史更新方向；权重衰减限制参数幅度。训练过程中检查损失是否有限，发现NaN或无穷大时停止。

### 6.2 过程记录

每100次更新记录一次学习率、训练损失、训练准确率及累计耗时。损失按实际图片数量加权，准确率为预测正确图片数占处理图片数的比例。两种模型各产生640行过程记录。



### 6.3 最终测试与结果保存

完成64000次更新后保存模型状态，包括可学习参数和BN运行统计量。随后切换为 `model.eval()`，并在 `torch.no_grad()` 下对全部10000张测试图片进行评估，不更新模型参数或BN统计量。

本实验使用Top-1准确率、错误率和平均交叉熵损失评价模型。Top-1准确率为最高分预测与真实标签一致的图片比例，错误率为100%减准确率。测试损失按各批实际样本数加权，最后16张图片完整计入。

最终保留训练CSV、模型状态文件和结果文本。

## 8. 结果分析与讨论

### 8.1 增加深度在本次实验中的收益

在相同数据预处理和更新安排下，ResNet56的测试准确率比ResNet20提高1.44个百分点，10000张测试图片中多预测正确144张，测试损失由0.3561降至0.3354。训练后期的窗口损失也更低。

这些结果表明，在本次设置下，增加残差块数量能够获得更好的最终测试表现。两组模型均实现了有效训练，56层模型没有出现仅因层数增加而无法降低训练损失的现象。不过，由于没有相同深度的普通网络对照，本实验不能据此独立证明残差连接解决了退化问题。

### 8.2 识别效果与训练成本的权衡

ResNet56的参数量约为ResNet20的3.16倍，实际训练时间约为1.71倍，多用25.92分钟，换取1.44个百分点的测试准确率提升。

如果优先考虑本次分类效果，56层模型更合适；如果更重视较少参数和较短训练时间，20层模型已经能以36.71分钟达到91.71%的测试准确率。

### 8.3 与论文设置的关系

本实验采用论文明确给出的主要结构和训练安排，但使用本机单GPU实现，没有重复论文确定训练安排时的45000/5000验证过程。因此，结果应解释为论文方法在当前实现和环境下的一次实践验证，不将其表述为论文成绩的严格复现。



## 9. 实验结论

本实验实现了CIFAR版本ResNet20和ResNet56，完成从随机初始化开始的64000次参数更新，并保存最终模型、完整训练记录和测试结果。两种模型的测试准确率分别为91.71%和93.15%，训练耗时分别为36.71分钟和62.63分钟。

在当前条件下，ResNet56以更多参数和更长训练时间取得更好的分类效果，体现了网络深度与训练成本之间的权衡。本实验完成了论文主要方法的实现与运行验证，结论依据实际训练和测试记录。
