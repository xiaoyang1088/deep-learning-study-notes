# 实验21：ResNet50在ImageNet100上的训练与测试

## 1. 实验内容

本实验参考《Deep Residual Learning for Image Recognition》的瓶颈残差结构，使用PyTorch自行实现ResNet50 v1.5，在ImageNet中选取100类图片，从随机初始化开始训练100轮，不使用预训练权重。训练完成后，根据验证集准确率选出最佳模型，在测试集上进行评估。

本次训练使用矩池云单张NVIDIA A100-PCIE-40GB显卡，训练及逐轮验证耗时约5小时1分27秒。完成100轮后，加载第96轮保存的最佳模型 `best.pt` 进行最终测试，准确率为 **81.69%**。

## 2. 模型设计

模型采用ResNet50 v1.5，包含16个瓶颈残差块，四个阶段的块数分别为3、4、6、3。100类模型共有 **23712932个可学习参数**。

| 位置 | 结构 | 输出尺寸，不含批次维 |
|---|---|---|
| 输入 | RGB图片 | 3×224×224 |
| 入口卷积 | 7×7卷积，步幅2；BN、ReLU | 64×112×112 |
| 最大池化 | 3×3，步幅2 | 64×56×56 |
| 第一阶段 | 3个瓶颈块 | 256×56×56 |
| 第二阶段 | 4个瓶颈块，首块下采样 | 512×28×28 |
| 第三阶段 | 6个瓶颈块，首块下采样 | 1024×14×14 |
| 第四阶段 | 3个瓶颈块，首块下采样 | 2048×7×7 |
| 全局平均池化 | 每个通道的空间位置取平均 | 2048×1×1 |
| 分类层 | 展平后通过2048→100的全连接层 | 100 |

每个瓶颈块包含1×1、3×3、1×1三层卷积。前两层卷积后接BN和ReLU，第三层卷积后接BN，再与捷径相加，经过ReLU输出。块的输出通道数是内部通道数的4倍。

输入与输出形状相同时使用恒等捷径；形状变化时，使用1×1卷积和BN调整捷径。下采样的步幅2放在主分支3×3卷积中。

这里采用v1.5的步幅位置；原论文瓶颈结构将下采样步幅放在前面的1×1卷积中。四个阶段的块数和瓶颈结构沿用论文设计。

按入口卷积、主分支卷积及分类层计算深度：

```text
1＋(3＋4＋6＋3)×3＋1＝50
```

正式训练前，使用1000类模型与torchvision参考实现进行检查。加载相同参数后，CPU和CUDA前向结果的最大绝对差均为0.0，梯度计算和参数更新检查通过。

## 3. 数据与训练设置

图片从ImageNet官网下载。本实验使用随机种子42，从1000类中固定选取100类。检查后排除74条重复或标签冲突记录，保留133908张图片，划分如下：

| 集合 | 图片数 | 用途 |
|---|---:|---|
| 训练集 | 116047 | 更新模型参数 |
| 验证集 | 12868 | 每轮评估，选择最佳模型 |
| 测试集 | 4993 | 训练结束后进行最终测试 |

训练图片随机裁剪并缩放至224×224，以0.5概率水平翻转；验证和测试图片将短边缩放至256，再中心裁剪224×224。图片转换为张量时，将像素从0～255映射到0～1，再使用均值 `[0.485, 0.456, 0.406]` 和标准差 `[0.229, 0.224, 0.225]` 进行标准化。

| 项目 | 设置 |
|---|---|
| GPU | NVIDIA A100-PCIE-40GB，单卡 |
| 系统、Python | Ubuntu 22.04、Python 3.11 |
| PyTorch、torchvision | 2.6.0+cu124、0.21.0+cu124 |
| 训练轮数 | 100 |
| 批次大小 | 128 |
| 数据加载进程数 | 4 |
| 损失函数 | 交叉熵损失 |
| 优化器 | SGD |
| 动量 | 0.9 |
| 权重衰减 | 0.0001 |
| 随机种子 | 42 |

| 训练轮次 | 学习率 |
|---|---:|
| 1～30 | 0.1 |
| 31～60 | 0.01 |
| 61～90 | 0.001 |
| 91～100 | 0.0001 |

每轮训练906个完整批次，100轮共更新90600次参数。每轮结束后进行验证，保存验证准确率最高的模型，测试集不参与模型选择。

## 4. 实验结果

| 指标 | 结果 |
|---|---:|
| 完成训练轮数 | 100 |
| 训练及逐轮验证耗时 | 5小时1分27秒 |
| 最佳模型轮次 | 第96轮 |
| 最佳验证准确率 | 84.64% |
| 测试准确率 | **81.69%** |
| 测试错误率 | 18.31% |
| 测试交叉熵损失 | 0.7562 |

**以上测试结果来自第96轮的 `best.pt`。** 训练仍然完成了100轮，第100轮模型另存为 `final.pt`，其验证准确率为84.49%；本次没有另测 `final.pt` 的测试准确率。

以下数据取自逐轮训练记录：

| 轮次 | 学习率 | 训练损失 | 训练准确率 | 验证准确率 |
|---|---:|---:|---:|---:|
| 1 | 0.1 | 4.5654 | 2.65% | 5.39% |
| 30 | 0.1 | 1.2444 | 67.02% | 62.12% |
| 31 | 0.01 | 0.9255 | 75.38% | 80.18% |
| 60 | 0.01 | 0.5595 | 84.63% | 81.23% |
| 61 | 0.001 | 0.4818 | 87.00% | 83.70% |
| 90 | 0.001 | 0.3741 | 90.06% | 84.50% |
| 96 | 0.0001 | 0.3602 | 90.38% | 84.64% |
| 100 | 0.0001 | 0.3638 | 90.33% | 84.49% |

训练损失从第一轮的4.5654降至最后一轮的0.3638。前两次降低学习率后，验证准确率分别从62.12%提高到80.18%、从81.23%提高到83.70%。第91轮第三次降低学习率后，验证准确率提升较小，第96轮达到最高值84.64%。最终加载第96轮模型测试，准确率达到81.69%。该结果对应本实验选取的100类子集。

实验输出统一保存在 `/mnt/c/Users/34138/Desktop/深度学习/01_ResNet/21_resnet50/outputs`，本次结果位于其中的 `resnet50_run01` 子目录，即仓库内的 `01_ResNet/21_resnet50/outputs/resnet50_run01`：

| 文件 | 本次保存内容 |
|---|---|
| `best.pt` | 第96轮模型，验证准确率84.64%，用于最终测试和后续预测 |
| `final.pt` | 第100轮模型，验证准确率84.49% |

完整运行日志为 `outputs/resnet50_run01.log`。

两个 `.pt` 文件均保存模型参数、BN运行统计量、类别表、轮次、验证准确率和命令行参数。命令行参数包括项目目录、输出目录、训练轮数、批次大小和数据加载进程数。未保存优化器状态，当前程序不支持断点续训。`best.pt` 是文件名，第96轮保存在文件内部的 `epoch` 字段中。

## 5. 运行方式

运行环境为Python 3.11、PyTorch 2.6.0+cu124和torchvision 0.21.0+cu124，正式训练需要支持CUDA的显卡。

本仓库公开模型、数据检查、训练、测试与预测代码。原始图片从ImageNet官网下载后，由本人完成100类子集的整理、检查与划分。数据获取脚本暂不公开，图片和模型权重也未包含在代码仓库中。以下训练命令以图片、类别表及固定划分清单已经准备好为前提：

| 路径，相对于本实验目录 | 内容 |
|---|---|
| `data/imagenet100_raw/` | 解压后的图片，按 `train/类别/图片` 和 `val/类别/图片` 存放 |
| `metadata/classes.json` | 本实验固定的100类及标签对应关系 |
| `metadata/splits_seed42/train.csv` | 训练集清单 |
| `metadata/splits_seed42/val.csv` | 验证集清单 |
| `metadata/splits_seed42/test.csv` | 最终测试集清单 |
| `metadata/splits_seed42/data_audit.json` | 状态为 `complete` 的数据检查与划分记录 |

上述类别表、清单和检查记录由本项目的数据准备过程生成。仅克隆代码仓库不会自动获得全部训练数据及配套文件。单张图片预测还需要先准备相应的模型权重文件。

以下命令均在 `01_ResNet/21_resnet50` 目录运行。

本机WSL中先进入该目录：

```bash
cd /mnt/c/Users/34138/Desktop/深度学习/01_ResNet/21_resnet50
```

先检查模型：

```bash
python checks.py --check model --device cuda
```

若另有本项目打包阶段生成的 `imagenet100_manifest.csv` 和 `imagenet100_packages.json`，可将它们放在 `data/packages/imagenet100_packages/`，再运行以下命令检查图片并生成固定划分。该步骤依赖未公开的数据获取过程，并非克隆仓库后可直接执行的下载命令：

```bash
python -u prepare_data.py --audit-and-split
```

本次数据检查和划分已经完成，已有完整清单时跳过上述准备命令。重新训练时使用尚不存在的输出目录，例如：

```bash
python -u train.py --project-dir . --output-dir outputs/resnet50_run02 --epochs 100 --batch-size 128 --num-workers 4
```

该命令会完成训练、逐轮验证、模型保存和最终测试。批次128为本次A100 40GB环境使用的设置。

直接使用本次已下载的第96轮 `best.pt` 预测单张图片，无需重新训练。将 `/path/to/image.jpg` 替换为实际图片路径：

```bash
python predict.py --checkpoint outputs/resnet50_run01/best.pt --image /path/to/image.jpg
```

如果重新执行了上面的 `resnet50_run02` 训练，则预测时改用新实验保存的最佳模型：

```bash
python predict.py --checkpoint outputs/resnet50_run02/best.pt --image /path/to/image.jpg
```

新一次训练的最佳轮次以其结果记录为准。

程序输出概率最高的5个类别。`predict.py` 用于单张图片识别，报告中的测试准确率由 `train.py` 的最终测试产生。
