## 实验 03：完整前向追踪

### 实验设置

- 模型：`torchvision.models.resnet18(weights=None)`，未加载预训练权重。
- 输入：随机生成的模拟彩色图片，形状为 `[2,3,224,224]`。
- 模式：`model.eval()` 与 `torch.no_grad()`，仅执行前向计算。
- 比较方式：复用同一个模型和同一批输入，对比逐层计算与 `model(images)`。
- 不执行反向传播或优化器更新，前后使用同一套参数。

### 完成内容与形状汇总

完成从输入图片到分类分数的完整前向追踪。下表采用“批次数、通道数、高、宽”的顺序；展平之后采用“批次数、特征数”。

| 位置 | 输出形状 |
| --- | --- |
| 模拟输入 | `[2,3,224,224]` |
| 入口卷积 conv1 | `[2,64,112,112]` |
| 入口 BN 与 ReLU | `[2,64,112,112]` |
| 最大池化 maxpool | `[2,64,56,56]` |
| 第一残差阶段 layer1 | `[2,64,56,56]` |
| 第二残差阶段 layer2 | `[2,128,28,28]` |
| 第三残差阶段 layer3 | `[2,256,14,14]` |
| 第四残差阶段 layer4 | `[2,512,7,7]` |
| 全局平均池化 avgpool | `[2,512,1,1]` |
| 展平 flatten | `[2,512]` |
| 全连接分类层 fc | `[2,1000]` |

### 验证结果

本次运行中，两类残差块拆分比较及完整前向比较均为 True，完整前向最大绝对差为 0.0（脚本没有固定随机种子，不同运行的具体分数可能不同）

### 关键认识

- **恒等捷径**：输入与主分支形状相同时，直接相加；基本块的完整输出为 `ReLU(F(x) + x)`。
- **变换捷径**：形状不匹配时，以带步幅的 1×1 卷积和 BN 调整输入，再相加；完整输出为 `ReLU(F(x) + P(x))`。这里 P 表示整个捷径变换，不是原样复制输入。
- **ResNet18 的层数**：入口卷积 1 层，加上 8 个基本残差块各 2 层主分支卷积，再加全连接 1 层，共 18 层。

### 结论边界

本实验验证了前向计算流程及实现调用的一致性，**没有训练模型，也没有评估识别准确率**。输出是随机初始化模型对模拟输入产生的分类分数。
