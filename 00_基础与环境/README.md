## 当前理解

- PyTorch 张量使用 `shape` 表示各维度大小，使用 `ndim` 表示维度数量。
- 单张彩色图像通常使用 `[C,H,W]`，批次图像使用 `[N,C,H,W]`。
- `unsqueeze`、`squeeze` 和 `permute` 用于调整张量维度。
- 普通图片通常使用 `uint8` 和 `0～255`，模型输入通常转换为 `float32`。
- 广播可以让不同但兼容的形状共同参与计算。
- `*` 表示逐元素乘法，`@` 表示矩阵乘法。
- `nn.Linear` 使用权重和偏置完成 `y=xWᵀ+b`。
- 损失函数用于衡量预测值与目标值的差距。
- `backward()` 计算梯度，梯度保存在参数的 `.grad` 中。
- 优化器根据梯度更新参数，训练循环会重复前向计算、反向传播和参数更新。
- ReLU 计算 max(0, x)，不是绝对值；ReLU(x) + ReLU(-x) 才能得到绝对值。
- 自定义 nn.Module 通过 forward() 定义计算过程，nn.Sequential 按给定顺序运行各个模块。
- copy_() 将数值复制到已有张量中，末尾的下划线表示原地修改。
- torch.from_numpy() 创建的张量与原数组共享内存，torch.tensor() 会复制数据。
- 本次实验中，CPU 张量调用 numpy() 得到的数组与张量共享内存。
- logits 是原始分类分数，不是概率；softmax 将每个样本的类别分数转换为概率。
- 对形状为 [样本数, 类别数] 的输出，dim=1 表示沿类别维度计算。
- argmax 返回最大值的位置，用于得到预测类别编号。
- enumerate() 提供位置编号和元素，两个循环变量通过解包按顺序接收它们。
- 使用整数类别标签时，CrossEntropyLoss 接收原始 logits 和 torch.long 类型的标签，不需要先计算 softmax。
- Dataset 的 __len__() 返回样本数量，__getitem__() 按索引返回特征和标签。
- batch_size 表示每批包含的样本数量，与每个样本的特征数量不同。
- DataLoader 将单个样本组合成批次；shuffle 改变读取顺序，但不破坏特征与标签的对应关系。
- iter() 创建迭代器，next() 获取下一批数据。
- backward() 根据链式法则计算梯度，optimizer.step() 使用梯度更新参数。
- 梯度默认会累加，因此本实验在每批训练前使用 optimizer.zero_grad() 清除旧梯度。
- 每轮训练完整遍历一次训练集，下一轮继续使用上一轮更新后的参数。
- model.train() 和 model.eval() 切换运行模式，不会直接更新参数。
- no_grad() 关闭代码块内的梯度记录，避免为验证计算建立反向传播所需的计算图。
- 验证阶段不执行 backward() 和 optimizer.step()，本实验的验证结果不会自动改变下一轮训练。
- 平均损失按样本数量计算，准确率为预测正确的样本数除以样本总数。

### 实验24的设置与结果

- 数据：八个二维样本，分为两个类别。
- 划分：六个训练样本、两个验证样本。
- 训练集原始索引：[4, 0, 7, 3, 2, 5]。
- 验证集原始索引：[1, 6]。
- 模型：nn.Linear(2, 2)。
- 优化器：SGD，学习率为0.1。
- 批次大小：2；训练轮数：10；参数更新次数：30。
- 随机种子：默认随机数生成器和数据划分生成器均设置为0。

| 轮次 | 训练损失 | 验证损失 | 验证准确率 |
| --- | --- | --- | --- |
| 1 | 0.057649 | 0.083809 | 100% |

| 10 | 0.020972 | 0.037195 | 100% |

本次运行中，训练损失和验证损失逐轮下降。验证准确率始终为100%，但验证损失继续下降，说明即使预测类别没有变化，模型给真实类别分配的概率仍可以提高。

验证集只有两个样本，而且数据规律简单，因此这里的100%仅用于验证训练流程，不能据此判断模型在真实任务中的泛化能力。

## 实验25～27：卷积神经网络基础

### 实验内容

- 实验25：使用固定卷积核进行二维卷积，观察步幅和填充对计算结果、输出形状的影响。
- 实验26：使用最大池化缩小空间尺寸，再将结果展平成一行数据。
- 实验27：将 Conv2d、ReLU、MaxPool2d、Flatten 和 Linear 组合成最小 CNN，观察完整前向传播。

### 五个步骤的作用

- Conv2d：对局部区域进行加权求和并加上偏置。不同输出通道使用不同的卷积核；同一卷积核在不同位置重复使用。
- ReLU：正数保持不变，负数变为零，为网络加入非线性，并不代表负数本身没有价值。
- MaxPool2d：分别在每个通道的小区域内取最大值，减少数据量，同时丢失部分细节。
- Flatten：将每个样本的通道、高、宽合并成一个维度，不改变数值。
- Linear：对展平后的数据进行加权求和并加上偏置，得到各类别的原始分数。

本实验中，Conv2d 和 Linear 有可训练参数；ReLU、MaxPool2d 和 Flatten 没有可训练参数。

### 实验27的设置

- 输入：一张单通道的 4×4 模拟图像，数值按行排列为1～16。
- 随机种子：0。
- 卷积层：输入通道1、输出通道2、卷积核3×3、步幅1、填充1，使用默认偏置。
- 池化层：窗口2×2、步幅2。
- 线性层：输入8个数，输出3个分类分数。

### 张量形状变化

| 步骤 | 输出形状 |
| --- | --- |
| 输入 | `[1, 1, 4, 4]` |
| Conv2d | `[1, 2, 4, 4]` |
| ReLU | `[1, 2, 4, 4]` |
| MaxPool2d | `[1, 2, 2, 2]` |
| Flatten | `[1, 8]` |
| Linear | `[1, 3]` |

池化后，每个样本包含2个通道，每个通道有2×2个数，因此展平后共有8个数。

### 实验27的结果

本次运行的原始分类分数约为：

`[0.311387, -0.885501, 0.578015]`

最大分数对应类别编号2。

本实验仅进行了前向传播，没有计算训练损失、反向传播和更新参数。卷积层与线性层仍使用随机初始化的参数，因此上述输出只能用于检查计算流程，不能说明模型已经具备图像识别能力。
